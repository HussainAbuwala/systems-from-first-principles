# Figma multiplayer

**Status:** Long-form episode complete; vertical Short in progress

## Central question

How can multiple people edit the same design at the same time without losing each other's work?

## Final progression

1. Save the whole document.
2. Send property-level changes instead of snapshots.
3. Give one authority responsibility for ordering accepted edits.
4. Preserve independent property changes and resolve actual conflicts.
5. Apply local edits optimistically while confirmation is pending.
6. Reconnect with fresh state and replay offline work.
7. Checkpoint volatile in-memory state.
8. Journal accepted changes between checkpoints.

This is an educational reconstruction. The [evidence map](research/evidence-map.md) distinguishes Figma's documented design from inference and teaching simplification.
